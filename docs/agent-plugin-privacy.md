# jdoc-test agent plugin privacy policy

The jdoc-test agent plugin provides two sets of instructions that help your coding agent write Spock and Gherkin tests in Java documentation.

## When you use the plugin

Your coding agent processes your prompts and the project files it uses for the task. Its privacy policy, permissions, and account settings govern how it handles that data, including retention and deletion.

The plugin has no publisher-operated backend, account system, or telemetry. It does not send prompts, source code, or test results to the jdoc-test maintainer. The maintainer therefore has no copy of that workspace data to retain, share, or delete.

## When you request support

If you open an issue, your GitHub username and the information you post are public. The maintainer uses the issue to respond to your request. Include only information you intend to share publicly. For a question about this policy or a request concerning an issue you posted, contact the maintainer through the [jdoc-test issue tracker](https://github.com/boolivar/jdoc-test/issues).

GitHub hosts the project website and issue tracker. Its privacy statement describes how it handles visitor and account data, including retention and requests for deletion. [GitHub General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)
